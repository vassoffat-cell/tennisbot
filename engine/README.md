# engine/ — документы проекта для облачных задач

Копия документов Claude-проекта «Standing in motion» (знания проекта в облачную задачу не передаются).
Источник истины — проект; чат разработки синхронизирует эти файлы. Облачная задача «Автопилот» читает и пишет здесь.

| Файл | Что |
|---|---|
| CODEX.md | **кодекс системы** — принципы, самообучение (selflearn.py), недельный аудит, форматы отчётов |
| CONTROL.md | реестр замечаний, контрольные точки, журнал ошибок — начало любой работы |
| AUDIT.md | регламент еженедельного аудита |
| REPORT_STYLE.md | оформление сообщений, §9 — закреплённые форматы отчётов |
| AUTOPILOT.md | регламент ежедневного автопилота, очередь гипотез, журнал |
| STATUS.md | текущее состояние, доступы, очередь |
| IMPROVE.md | бэклог гипотез точности и журнал проверок |
| TZ/TZ-004.md, TZ/TZ-005.md | ставка дня тенниса, каперы |
| research/ | скрипты бэктестов автопилота (A1, A1b, A2, A3) — для повторения проверок |
