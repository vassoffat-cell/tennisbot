# ТЗ-004 · Теннис: утренний цикл «скриншоты → анализ → ставка дня» (решение пользователя 10–11.11.2026)

Статус: внедрено 11.11.2026 (round4.py, pick.VALUE_ON, oddspapi.py — Pinnacle по теннису).

## Порядок (каждые сутки 08:00 → 08:00)
1. 08:07 — таблица всех матчей суток (без прогнозов).
2. Запросы скриншотов 1xBet по одному («Основная игра»: 1X2 и Тотал) → ✅ по каждому.
3. Анализ после последнего (не позднее 14:00): перевес = P_Pinnacle (Шин) × кф_1xBet − 1.
4. ⭐ ставка дня по СОВМЕЩЁННОМУ правилу: а) перевес ≥ 3% при кф 1,70–2,50 (П1/П2) → «📈 С перевесом»;
   б) иначе правило C (кф ≥ 1,35 → максимум справедливой P) с пометкой «⚠️ Без перевеса · матожидание −X%»;
   + таблица проверки + прогноз на 24 ч со строками 💡 (лучшая линия 1xBet по каждому матчу).
5. Кнопки ✅ / 🔄.

## Обоснование (история 2023–25, 14 825 матчей)
- «максимум P при кф ≥ 1,35»: 4 839 ставок, ROI −4,6% → только запасное правило;
- перевес ≥ 3% над Pinnacle, кф 1,70–2,50: 134 ставки, 59,0% при P 50,4%, ROI +23,5% ± 9,0; ожидание реалистично +3…+10%.

## Контроль
- 🚨 «с перевесом» после ≥ 30 ставок ROI значимо < 0 (z ≤ −2); 🚨 доля «без перевеса» > 80% за 14 дней; ⚠️ скриншоты не пришли 3 дня.
- Аудит: группы, ROI ± ошибка, охват Pinnacle, кредиты API; через 4–8 недель — предложение пользователю.
- Футбол: правило перевеса на истории не подтвердилось (−6,7% ± 9,5) → правило C с пометкой МО.
