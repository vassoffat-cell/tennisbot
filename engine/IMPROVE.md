# Штурм точности — бэклог гипотез и журнал проверок (копия проекта, сжатая; полная — engine/IMPROVE.md проекта)

Правило: гипотеза проверяется на истории (обучение / отложенная выборка) → внедряется только при росте точности; результат (+/− п.п., n) — сюда.
Порог шума: на ~10 000 проверочных матчей ±0,3 п.п. точности исхода (±0,45 п.п. для линий); признак берём, если растут И точность, И лог-лосс.
Исключение (T21): заведомо лучший оценщик берётся при значимом росте лог-лосса без ухудшений сверх шума.

## Где мы (11.11.2026)
- Теннис (модель V4 + T29 + T30): проверка 2023–26 WTA 66,6% / 0,6052, ATP 66,2% / 0,6096. Pinnacle без маржи точнее модели
  (2024–26: WTA 67,6% против 66,4%, ATP 68,7% против 66,0%); веса справедливой P: рынок 1,11 / модель −0,11 (pick.WEIGHTS).
- Футбол: Dixon–Coles, S — голы 50% + удары в створ 50% → исход 49,45% (07.2023–01.2026, n=18 171). Pinnacle 1X2 лог-лосс 0,9966
  против модели 1,0190.
- Линии откалиброваны: точность ≈ P (теннис фора 73%, тотал 75,6%, ИТ ≈74,7%; футбол тотал 76,9%, ИТ 74,8/73,5%, фора 77,5%).
  Линии тенниса — вариант Б с 11.11 (ближе к центру при P ≥ 0,65): WTA тоталы 66,2/66,8%, ATP 67,8/66,5%.
- Автопилот 11.11 (рынок как новая информация): ATP исход 66,0 → 68,5% и фора 65,8 → 67,2% при кф Pinnacle; футбол 1X2 53,0 → 55,4%,
  Т2,5 57,3 → 59,8% (лиги бота, 07.2024–11.2026); показываемые линии футбола 69,7 → 73,1% (порог 0,55, без ОЗ). Детали — STATUS.md.
- Вывод: по истории результатов — плато; прирост только из новой информации (рынок, травмы, составы, каперы) или отбора.

## T33 · «Ненужной информации не бывает» — скрытые факторы (12.11.2026, гипотезы пользователя)
Пользователь возразил выводу «рост, рука и т. п. — шум» и привёл доводы: разминочные турниры перед шлемами, азиатские игроки и хард,
домашний турнир и давление, рост и подача, любимые покрытия, возрастные игроки на траве, защита очков.
Метод (engine/research/t33_factors.py): срез, где признак ровно у одного игрока; факт побед против P модели до матча (V4, без утечки),
z = Σ(факт − P)/√ΣP(1−P); 2023–26, WTA и ATP отдельно, знак в половинах периода. Порог находки |z| ≥ 2,5 (проверок ~50).

Выводы: (1) пользователь прав — возраст на траве в ATP реальный неучтённый фактор (единственный, прошедший порог); вывод «шум» был
верен только для признаков по отдельности, не для сочетаний признак × покрытие × контекст. (2) Рост и рука сами по себе уже «внутри»
модели подачи (остаток ≈ 0) — добавлять их отдельно незачем; искать нужно сочетания. (3) Гипотеза «топы берегут себя перед шлемом»
на данных не видна (у WTA топ-10 — наоборот, +10,7 п.п., n мало). (4) Отложенная проверка возраст × трава ATP: β = +0,036 на год,
тест 2025–26 n 287: лог-лосс 0,6120 → 0,6046, угадано 67,2 → 68,3% (z −1,2) — направление подтверждено, ворота (n ≥ 1000) не пройдены → A12.
Хоккей тем же методом: гости второй день подряд при отдохнувших хозяевах — хозяева 61,9% против 53,5% (n 493, z +3,8; сезоны +2,6 / +2,8);
отложенный сезон: 53,8 → 54,9% (n 1705), срез 56,8 → 63,5% → внедрено (hockey/hrun.B2B_BETA = 0,30). Обратный случай незначим.
Правило на будущее: «шум» объявляется только после проверки сочетаний; каждая идея пользователя и аудита — срез T33.

### T33 · продолжение (12.11.2026, утро): хоккей — календарь, футбол — календарь и тотал, теннис — расширение
**Хоккей НХЛ** (engine/research/t33_hockey.py, n 3140, 2024–26, остаток «победа хозяев с ОТ»): кроме внедрённого A11 ничего значимого —
хозяева 2-й день подряд −5,7 п.п. (z −1,5; сезоны −2,2 / −0,1 — неустойчиво); гости 3-й матч за 4 дня +4,2 (z +1,8, пересекается с A11);
4-й+ матч выезда без «второго дня» +0,3; хозяева после 4+ дней отдыха +6,5 (z +1,6, n 138) — копим.
**Футбол** (engine/research/t33_football.py, n 8834, 07.2023 → 11.2026, против модели и против Pinnacle без маржи): усталость после
еврокубка (≤ 4 дней), короткий отдых, новички лиги, первый тур после перерыва, первые туры, середина недели — |z| ≤ 1,2 у модели и
у Pinnacle: скрытого календарного фактора исхода нет. Находка в контроле: модель занижает «больше 2,5» — факт 54,8% против 53,1% (z +3,3);
по сезонам +2,7 / +0,1 / +1,3 / +5,8 п.п. (текущий сезон, n 727, z +3,2), в концовке сезона +4,3 (z +2,9); Pinnacle это видит (z +1,2 / +0,4).
Постоянный сдвиг (обучение до 2025) на тесте не помогает (лог-лосс 0,6744 → 0,6743); скользящий сдвиг по последним 800 матчам:
0,6735 → 0,6729 (z −1,5), сторона 57,62 → 57,62% — ниже ворот, не внедрено. В бою тотал 2,5 идёт смесью с Pinnacle (A2) — перекос закрыт
там, где есть цена; следить за долей матчей без цены.
**Теннис, возраст × трава — расширение на 2021–22** (веса модели обучены на 2020–22, признаки — до матча): ATP старше на ≥ 6 лет:
2021–22 n 217 +1,3 п.п. (z +0,4); 2023–25 n 308 +9,7 (z +3,7); все сезоны n 525 +6,2 (z +3,1). WTA: 2021–22 +7,1 (z +2,2), 2023–25 +0,6.
Вывод: эффект в ATP есть, но слабее и менее устойчив, чем по 2023–25 (оценка ≈ +5–6 п.п.); травяной сезон 2026 в соединённых данных
отсутствует — добавить и перепроверить до июня 2027 (A12). Правило: первая оценка среза — верхняя граница, решает расширение периода.
