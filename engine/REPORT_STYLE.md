# Стандарт оформления отчётов и сообщений ботов (обязателен; сводка всех замечаний пользователя 08–11.11.2026)

Перед любым новым сообщением бота / отчётом / карточкой — пройти чек-лист в конце. Нарушение = ошибка, исправлять до внедрения.

## 1. Всё с цифрами — таблица
- Таблица как лист Excel: моноширинный блок `<pre>` (rtable.render / rtable.kv). 1-й столбец — название, **цель — в скобках**
  («Тотал (75%)»), дальше — количество (угадано/всего), %, цвет 🟢🟡🔴 в конце строки.
- Текстовые столбцы — по левому краю, числа — по правому. Разделы — строкой без цифр («До выводов»), подпункты — с отступом.
- **Сводка под таблицей — тоже таблица** («Сводка»: ⭐ Вчера, k по рынкам строкой на рынок, Дорасчитано, Ждут результата,
  Данные) — rtable.kv. Никаких строк-абзацев вида «🧠 k: Победа 1,06→1,03 · Фора …» (замечание 11.11).
- Сообщение без таблицы, где есть цифры по нескольким объектам, — ошибка.

## 2. Одна страница телефона
- Ширина таблицы ≤ 35 знаков (≈ 26–35); линия «─» не длиннее таблицы, иначе переносится на две строки (замечание 11.11).
- Имена — фамилии («Kostyuk–Pegula»), команды — коротко («Ланс–Марсель»); длинное значение — обрезать с «…».
- Минимум букв: без длинных фраз внутри строк, без слова «ожидание» (08.11); пояснение — **одной строкой легенды** под таблицей.

## 3. HTML не должен «вылезать»
- Блоки с разметкой (`<pre>`, `<b>`, `<i>`) отправлять отдельным блоком notify.send_blocks; **не передавать HTML в `extra` / `notes`**
  отчёта — там текст экранируется и пользователь видит `<pre>`, `</i>` (ошибка 11.11, карточка каперов).
- Проверка: отправленный текст не содержит видимых `<` `>`.

## 4. Полнота отчётов (11.11)
- Суточный: «▸ Матчи за сутки» — каждый матч со статусом ✅ ❌ ⚪ ⏳ 🕒 и **под ним каждая предложенная линия с итогом**
  («✅ ТМ 14.5 · 74%»). Линия пишется полностью: рынок + сторона + значение («ИТ1 Б 6.5», не «Б 6.5»).
- Недельный (понедельник): таблица недели + **все линии недели, сгруппированные по типу линии**, внутри — по дням (свёрнутые списки).
- Списки длиннее 3–4 строк — в сворачиваемой цитате (`<blockquote expandable>`, notify.folded).
- Каперы — одна карточка «👥 Каперы» (tipsbook.card): канал | угадано | % | ROI, ниже 2 строки (купоны Green Line, 🔥/⚔️).

- Тотал — одна фиксированная линия (T32: ATP 22,5 · WTA 20,5 · футбол 2,5): в отчёте отдельная строка «Тотал фикс.» с подстроками
  Б / М / P ≥ 60%; в общую строку «Линии» не входит. Не возвращать «плавающие» линии тотала (М 27,5–28,5) — они завышают точность.

## 5. Подтверждения и запросы — 1–2 короткие строки
«✅ Kostyuk–Pegula: П1 2,63 · П2 1,54», «📸 1/2 · 01:00 · Kostyuk–Pegula», «🔁 Ставка дня изменена (по каперам): …».

## 6. Карточки (аудит, внедрено, неделя)
Заголовок → таблица → разделы с иконками и пунктами «•» (📥 Данные / 🔎 Выводы / 🧮 Охват / 🛠 Сделано / ➡️ Дальше).

## 7. Цвета и значки (единые)
- Цвет строки: 🟢 цель доказана (нижняя граница 95% ≥ цели), 🟡 не доказана, 🔴 значимо ниже; цвет — с n ≥ 10.
- Итог: ✅ угадано · ❌ нет · ⚪ возврат/не состоялся (не в счёт) · ⏳ ждёт итога · 🕒 не начат.
- **Честный кф (решение 11.11.2026)** — на КАЖДОЙ линии и исходе во всех видах (теннис, футбол, хоккей): списки прогнозов,
  ставки дня, уведомления о правках. Формат «— 72% · честный кф 1,39» (= 1 / P, запятая, 2 знака; notify.fair). В шапке списка —
  пояснение «честный кф = 1 / вероятность: ставка в плюс, если кф букмекера выше».
- Синтез с каперами: 🔥 модель + капер за линию · ⚔️ конфликт · 👥 их ставки. ⭐1 — ставка дня (первый приговор), ⭐2/⭐3 — новые линии дня (каждая — отдельный закреп); ✏️ — мнение изменилось; ➕ — новая линия. 🔒 · — заглушка.
- Цвет фона цитат и блоков `<pre>` задаёт Telegram (цвет бота по его ID) — ботом не меняется (вопрос пользователя 11.11).

## 8. Конфиденциальность (11.11)
Боты — «Заметки Т» / «Заметки Ф», нейтральные аватары; последним сообщением после рассылки — «🔒 ·»; в текстах не упоминать
названия каналов-каперов вне карточки каперов; токены и секреты не показывать никогда.

## Чек-лист перед внедрением
1. Есть цифры по нескольким объектам → таблица? 2. Ширина ≤ 35, линия «─» не переносится? 3. Цель в скобках, легенда одной строкой?
4. Нет видимых HTML-тегов? 5. Линии записаны полностью? 6. Длинные списки свёрнуты? 7. Значки — из п. 7?
8. Проверено на образце (тест офлайн или пробная отправка) до внедрения.
