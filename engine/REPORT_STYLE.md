# Стандарт оформления отчётов и сообщений ботов (обязателен; сводка всех замечаний пользователя 08–14.11.2026)

Перед любым новым сообщением бота / отчётом / карточкой — пройти чек-лист в конце. Нарушение = ошибка, исправлять до внедрения.

## 0. ГЛАВНОЕ (решение пользователя 14.11.2026 10:08): все виды отчётов — ЁМКИЕ И ПОНЯТНЫЕ
Таблица и итог — сверху, подробности — в свёрнутых списках; месяц и год в «Аналитике» — только таблица; ни строк-подсказок,
ни повторов. Новый отчёт проходит этот пункт первым.

## 1. Всё с цифрами — таблица
- Таблица как лист Excel: моноширинный блок `<pre>` (rtable.render / rtable.kv). 1-й столбец — название, **цель — в скобках**
  («Тотал (75%)»), дальше — количество (угадано/всего), %, цвет 🟢🟡🔴 в конце строки.
- Текстовые столбцы — по левому краю, числа — по правому. Разделы — строкой без цифр («До выводов»), подпункты — с отступом.
- «Сводки» под таблицей нет (Г5, 14.11); никаких строк-абзацев вида «🧠 k: Победа 1,06→1,03 · …» — цифры только в таблице.
- Сообщение без таблицы, где есть цифры по нескольким объектам, — ошибка.

## 2. Одна страница телефона
- Ширина таблицы ≤ 35 знаков (≈ 26–35); линия «─» не длиннее таблицы, иначе переносится на две строки (замечание 11.11).
- Имена — фамилии («Kostyuk–Pegula»), команды — коротко («Ланс–Марсель»); длинное значение — обрезать с «…».
- Минимум букв: без длинных фраз внутри строк, без слова «ожидание» (08.11). **Легенд и подсказок нет (14.11)** — значки понятны без пояснений.

## 3. HTML не должен «вылезать»
- Блоки с разметкой (`<pre>`, `<b>`, `<i>`) отправлять отдельным блоком notify.send_blocks; **не передавать HTML в `extra` / `notes`**
  отчёта — там текст экранируется и пользователь видит `<pre>`, `</i>` (ошибка 11.11, карточка каперов).
- Проверка: отправленный текст не содержит видимых `<` `>`.

## 4. Полнота отчётов (11.11)
- Суточный: «▸ Матчи за сутки» — каждый матч со статусом ✅ ❌ ⚪ ⏳ 🕒 и **под ним каждая предложенная линия с итогом**
  («✅ ТМ 14.5 · 74%»). Линия пишется полностью: рынок + сторона + значение («ИТ1 Б 6.5», не «Б 6.5»).
- Недельный (понедельник): таблица недели + **все линии недели, сгруппированные по типу линии**, внутри — по дням (свёрнутые списки).
- Списки длиннее 3–4 строк — в сворачиваемой цитате (`<blockquote expandable>`, notify.folded).
- Каперы — сообщение ② отчёта (caprep.report); у футбола ниже — таблица каналов (tipsbook.card): канал | угадано | % | ROI.

- Тотал — одна фиксированная линия (T32: ATP 22,5 · WTA 20,5 · футбол 2,5): в отчёте отдельная строка «Тотал фикс.» с подстроками
  Б / М / P ≥ 60%; в общую строку «Линии» не входит. Не возвращать «плавающие» линии тотала (М 27,5–28,5) — они завышают точность.

## 5. Подтверждения и запросы — 1–2 короткие строки
«✅ Kostyuk–Pegula: П1 2,63 · П2 1,54», «📸 1/2 · 01:00 · Kostyuk–Pegula», «🔁 Ставка дня изменена (по каперам): …».

## 6. Карточки (аудит, внедрено, неделя)
Заголовок → таблица → разделы с иконками и пунктами «•» (📥 Данные / 🔎 Выводы / 🧮 Охват / 🛠 Сделано / ➡️ Дальше).

## 7. Цвета и значки (единые)
- Цвет строки: 🟢 цель доказана (нижняя граница 95% ≥ цели), 🟡 не доказана, 🔴 значимо ниже; цвет — с n ≥ 10.
- Итог: ✅ угадано · ❌ нет · ⚪ возврат/не состоялся (не в счёт) · ⏳ ждёт итога · 🕒 не начат.
- **Что видит пользователь (11.11.2026)** — только результаты и развитие: ⭐ ставки дня, отчёты, тревоги, самообучение, аудит.
  Списки прогнозов не публикуются (PUBLISH_LISTS=False); прогнозы каперов — каждый отдельным сообщением с вердиктом (CAPPER_ALERTS=True, Г2а, К16).
- **Начало сообщения ставки дня (11.11.2026)** — единое, без даты (через 24 ч закреп снимается): «🎾1 Теннис · ставка дня»,
  «⚽1 Футбол · ставка дня», «🏒1 Хоккей · ставка дня»; значок вида спорта вместо ⭐, цифра — номер ставки (1–3).
  Правка: «🎾1 Теннис · ставка дня: мнение изменилось ✏️ (причина)».
- **⭐1 — вторая строка «🔎» (15.11.2026 19:44):** «🔎 Сутки: 3 матча · 21 линия · на ставку дня — 2» и строка турниров / лиг
  («ATP Finals, хард 2 · WTA Finals Indian Wells, хард 1 · 🔏 9eedf7de»). Команды не перечисляются. Фиксируется на старте суток,
  при правках не меняется. 🔏 — код снимка всех линий суток (seal.py, файл <data>/seal/<вид>_ГГГГ-ММ-ДД.csv в репозитории).
- **⭐ — строка «💵» (16.11.2026, С17):** под «… · честный кф 1,44» — «💵 1xBet 1,52 · EV +5,5%» (≈ перед кф — оценка по Pinnacle;
  нет кф — строки нет). В отчёте ③ строка ставки: «… · 69% · кф 1,52 · EV +5,5%».
- **Сбой прогона (11.11.2026)** — в чат только «⚠️ Футбол: прогон ЧЧ:ММ не завершён» + причина по-русски одной строкой
  (notify.crash); трейсбек — только в журнале GitHub. Уведомление удаляется само после первого успешного прогона (data/crash.json).
- **Честный кф (решение 11.11.2026)** — на КАЖДОЙ линии и исходе во всех видах (теннис, футбол, хоккей): списки прогнозов,
  ставки дня, уведомления о правках. Формат «— 72% · честный кф 1,39» (= 1 / P, запятая, 2 знака; notify.fair). Пояснение в шапке
  убрано 14.11 (подсказки не нужны).
- Синтез с каперами: 🔥 модель + капер за линию · ⚔️ конфликт · 👥 их ставки. ⭐1 — ставка дня (первый приговор), ⭐2/⭐3 — новые линии дня (каждая — отдельный закреп); ✏️ — мнение изменилось; ➕ — новая линия. 🔒 · — заглушка.
- Цвет фона цитат и блоков `<pre>` задаёт Telegram (цвет бота по его ID) — ботом не меняется (вопрос пользователя 11.11).

## 8. Конфиденциальность (11.11; 21.11 — скрытый текст, В3б)
**21.11:** каждое сообщение ботов отправляется и правится скрытым текстом Telegram (`<tg-spoiler>`, notify.hide — автоматически в notify._call): текст под точками, нажатие — показать, выход из чата — снова скрыто. Таблицы `<pre>`/`<code>` Telegram под spoiler не прячет (spoiler_probe.py), поэтому с 23.11 они идут простым текстом и скрыты вместе со всем (notify.PRE_PLAIN). Ответы меню Apps Script — тоже скрыты (hide_, Code.gs установлен 23.11). Новых сообщений без скрытия не бывает.
Боты — «Заметки Т» / «Заметки Ф», нейтральные аватары; последним сообщением каждого прогона — тихая контрольная точка «🔒 ЧЧ:ММ · 🎾🏒 / ⚽ проверка ✓ ⏎ ⭐ без изменений · далее ЧЧ:ММ» и «🔒 ЧЧ:ММ · 👥 каперы ✓ ⏎ новых нет · далее ЧЧ:ММ» (В3а; было — «прислано N ↑»; пропуск — «⚠️ прошлая проверка пропущена»); в текстах не упоминать
названия каналов-каперов вне карточки каперов; токены и секреты не показывать никогда.

## Чек-лист перед внедрением
1. Есть цифры по нескольким объектам → таблица? 2. Ширина ≤ 35, линия «─» не переносится? 3. Цель в скобках, НЕТ строк-легенд и подсказок?
4. Нет видимых HTML-тегов? 5. Линии записаны полностью? 6. Длинные списки свёрнуты? 7. Значки — из п. 7?
8. Проверено на образце (тест офлайн или пробная отправка) до внедрения.

### Сообщение капера — вердикт (К15/К16, 20–21.11)
Последняя строка карточки: вердикт · «пост ↗». Варианты (ровно один):
`🔥 система согласна (P 69%)` · `⚔️ система против (P 34%)` · `· система нейтральна (P 52%)` — наш матч (P ставки дня: рынок + модель, 24.11);
`🔥 рынок за (P 64%)` · `⚔️ рынок против (P 38%)` · `· рынок нейтрален (P 50%)` — другая лига, P по цене DraftKings (ESPN);
`⬜ наш матч, рынок вне модели (фолы, угловые…)` · `⬜ рынок вне модели (фолы, угловые…)` (ставки на таймы — с вердиктом, К17; ярлык «ТБ1.5 · 1-й тайм», «П1 оба тайма», «тайм/матч П1/П1») · `⬜ лига вне модели, цен нет` · `⬜ вид спорта вне модели (ставка на спортсмена)` · `⬜ матч не найден на табло`;
пост «LIVE» без названия матча — `🔴 LIVE — опубликован во время матча, не оценивается`;
после начала матча — строка времени `🔴 опубликован в ЧЧ:ММ, матч идёт с ЧЧ:ММ` и `· после начала — не оценивается`.
Старое `⬜ вне базы системы` не используется. Над вердиктом — строка времени `⏰ начало ЧЧ:ММ` / `⚠️ матч уже идёт` / `🔴 …` (К8).

### Снятая ставка дня (С2а, 21.11)
Закреп редактируется и открепляется: «⚽1 <b>Футбол · ставка дня снята</b> ❌ ⏎ Матч ⏎ <s>ТБ2</s> — рынок против: P 72% → 58%, кф 1,43, EV +3,2% → −17,1% (в ЧЧ:ММ)»;
то же отдельным сообщением. Правка по той же причине — обычное «мнение изменилось ✏️ (рынок против: …)». В отчёте ③ — строки «❌ Снятые ⭐» и «снятие право (L) x/y».
