**Поправка (17.11 12:24 написано неверно):** «ТМ22.5 Медведев — Cobolli, EV +13%» — это P модели (59%). Справедливая P рынка
(Pinnacle 1,93 / 1,95, Шин; веса A1) — 49% → EV по кф 1,92 = −6,5%. По правилам версии 2 этот матч ⭐ НЕ стал бы; П1 Медведев
(кф 1,29, справедливая P 0,757) — EV −2,3%, тоже нет. Честный итог 16.11 по новым правилам: **теннисной ⭐ не было бы** (нет выгоды),
🏒1 КХЛ — тоже нет (нет цены, устаревшие силы). Два проигрыша — не «невезение», а два нарушения: ставка без цены и ставка
на устаревших данных; оба закрываются правилами ниже.

**Главный вывод шага 0:** у системы сейчас нет доказанного способа давать плюс в большинство дней. Нынешний выбор ≈ −маржа
(−3…−5%), единственный доказанный плюс — 💰 в узком сегменте и редко. Поэтому ставка дня не может быть «каждый день по лучшей P»:
либо редкая 💰, либо честное «выгодной нет», а поиск новых источников плюса — в теневом портфеле (лучшая цена из 10 книг, время
ставки, ниши), с воротами на сотнях ставок, а не на одном дне.

## 2. Правила ставки дня (версия 2)
| № | Правило | Почему |
|---|---|---|
| R1 | ⭐ только при цене рынка: кф 1xBet есть (API / скриншот) и есть справедливая P рынка (Pinnacle, Шин; где Pinnacle нет — 1xBet без маржи, вес blend) | нет цены — нечего проверять |
| R2 | P для решения = P рынка с весами A1/A2 (рынок 1,11, модель −0,11); P модели — только в теневом портфеле | модель не лучше рынка (A1, A28, A30) |
| R3 | EV = P × кф 1xBet + P(возврат) − 1. 💰 — EV 3–20% ТОЛЬКО в доказанном сегменте (теннис П1/П2, кф 1,70–2,50); все остальные рынки и виды — в ⭐ только после ворот R7 | шаг 0: на всех кф EV ≥ 3% не даёт плюса (+1,2%, z 0,2 в обоих периодах) |
| R4 | Лимита количества нет (С7а): ⭐ — каждый матч, прошедший R1–R3, одна на матч, защитный потолок 8 в сутки на вид | решение пользователя 17.11 |
| R5 | ✅ 17.11 14:23 решено — «лестница» (CONTROL С23): ⭐ каждый день; 💰 — 1 ед., иначе 🎯 с max EV (не max P) — ¼ ед.; история: max P −6,2% / −4,5% → лестница со ставками +3,1% / +5,3%. | R6 | После старта последнего матча ⭐ вида — пересчёта нет; контрольная точка «⭐ сыграна, ждём итог ЧЧ:ММ» | замечание пользователя 17.11 12:16 |
| R7 | Сегменты без доказательства (тоталы, форы, ИТ, футбол, хоккей) идут в ⭐ по R3 только после ворот теневого портфеля: n ≥ 300, CLV > 0 (t ≥ 2), ROI ≥ 0; до ворот — «мягкий» режим R5 | не принимать решение на одном дне |
| R8 | Хоккей: ⭐ только на линиях с ценой (A31) и по правилам 1xBet — в тексте «осн. время» или «с ОТ» (сверка по скриншоту пользователя); КХЛ — Л7 | 15.11 Dallas ИТ1 Б1.5: L по осн. времени, W с ОТ |

## 3. Теневой портфель (основа решений)
- Каждый прогон: все кандидаты с ценой → лист **shadow** (теннис и хоккей — таблица Tennis, футбол — Football): дата, вид, лига, матч,
  рынок, исход, линия, начало, P модели, P рынка, кф 1xBet, лучший кф + книга, EV по 1xBet и по лучшему, ступень, 🔥/⚔️; одна строка на
  (матч, рынок, исход, линия) — обновляется до старта (последняя цена = цена закрытия).
- Итог и CLV: теннис — снимки Pinnacle (цикл ⭐), футбол — DraftKings из ESPN (dk_*, каждые 2 ч, бесплатно), хоккей — DK pickcenter.
