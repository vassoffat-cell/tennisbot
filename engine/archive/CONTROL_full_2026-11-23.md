## 4. Как работать дёшево (порядок для любого чата и задачи)
1. `python3 engine/health.py 26` → таблица ✅/❌. Всё ✅ — к задаче; ❌ — сначала чинить, строка в раздел 3.
2. Нужен лог — только конкретного прогона: `gh run view <id> --log | grep -E "ставка дня|отчёт|сбой|🏒"`. Не качать все логи.
3. Нужны данные — лист Google (day_pick, dp_changes, hk_day_pick, hk_games) точечным диапазоном.
4. После изменения: офлайн-тест → push → ОДИН облачный прогон → `health.py 2`.
5. Новое замечание пользователя — строкой в раздел 1 этого файла в том же коммите, ОБЯЗАТЕЛЬНО с колонкой «Проверка»: аудит
   проходит каждую строку §1 по этой колонке (AUDIT.md п. 0а) — так ни одно нововведение не выпадает из аудита.
6. Коммит — только явными путями (`git add <файлы>`), не `git add -A`: py_compile и запуски пишут __pycache__ (14.11 дважды попали в коммит).
   Отслеживаемые __pycache__ не удалять (`git checkout -- __pycache__`), новые — не добавлять.
