## 4. Ставка дня (dpcore.py — теннис/футбол, hockey/hpick.py — хоккей; правила — CONTROL С19–С27)
- **Цена:** кф ⭐ — лучшая цена среди контор The Odds API (1xBet, Pinnacle, Marathon, William Hill, Unibet, Betsson, 888sport, Betclic,
  биржи Betfair/Matchbook за вычетом комиссии; С25а); справедливая P — Pinnacle без маржи по Шину (+ модель с весом −0,11).
- **Лестница (С23):** есть 💰 (перевес над справедливой Pinnacle 3–20%, П1/П2, кф 1,70–2,50; теннис) — каждая своя ⭐, ставка 1 ед.;
  нет — 🎯 с максимальным EV среди P ≥ 0,60, кф ≥ 1,35, EV ≥ −3%, ставка ¼ ед.; правка — при EV лучше на 2 п.п.
- **Сколько ⭐ (С23а, решение 21.11):** 🎯 — до 3 в сутки на вид (теннис, футбол, хоккей), лучшие по EV, каждая — свой матч и свой
  игровой отрезок ≥ 2 ч (С14), могут появиться днём; ≈ 2 плюса и 1 минус в сутки (P ≈ 0,65), сутки без минуса ≈ 27% — пользователь в курсе.
- **Снятие ⭐ (С2а, 21.11):** на каждой перепроверке ⭐ должна проходить порог; не проходит при свежей цене — правка на линию того же матча
  или «❌ снята — рынок против»; снятая получает итог отдельно (отчёт ③ «снятые ⭐ · снятие право»), её отрезок свободен для другой 🎯.
- **EV (исправлено 21.11):** P целых линий (Ф 0, ТБ 2, ТБ 3) — без возврата → EV = (1 − P возврата)·(P·K − 1); раньше возврат учитывался
  дважды (EV завышался на 20–25 п.п., лестница тянулась к целым линиям). Любой EV > 20% — сначала проверка формулы и данных.
- **Фильтр «модель против рынка» не нужен (21.11, dp_agree.py, n 1 992):** угадано 64,5% против 65,2% — не помогает; рынок откалиброван (65,2 / 65,1%).
- **Хоккей (С26, С26а):** только линии с ценой (1xBet / Marathon — основное время), P ≥ 0,55, ¼ ед.; нет цены — «ставки нет».
- **Синтез (Ц14, 21.11):** один порядок для ⭐1, доп. 🎯, правки и снятия во всех видах — 💰 → 🔥 каперов → EV → ⚔️; пониженный сегмент
  самообучения — не в новую ⭐ и не в правку; вето ✔ — вне выбора. Каперы: ✔ доказанные и близкие к ✔ (n ≥ 50, z ≥ 1,0, ROI > 0 — сейчас
  Green Line · футбол) — 🔥 поднимает, ⚔️ опускает; вето и снятие — только ✔; 🔥/⚔️ остальных — значок. Подробно — PRINCIPLES «Синтез».
- **Цель ⭐ — 100% (Ц12):** каждый промах — 🔴 инцидент с причиной (③, incidents.csv, learning), разбор на аудите (0е); «серия без промаха» в ③.
- **Утром** — первый приговор (теннис/футбол 08:00, хоккей 12:00), отдельный закреп; после начала матча ставка заперта («сыграны, ждём итог»).
- **Учёт:** day_pick / dp_changes / hk_day_pick (k, ev, k_best, p_close, clv); банк в отчёте ③ (С27); теневой портфель — каждая сторона с ценой (С21).

## 7. Самообучение и аудит
- **После каждого суточного отчёта** — selflearn.cycle (CODEX §2, О1–О9):

  - лимит ставок;

## 10. Как работать (чат разработки) — дёшево и без ошибок
1. **Начало:**
   - add_repo vassoffat-cell/tennisbot (push) → `git clone` в /home/claude/tennisbot;
   - `python3 engine/health.py 26`;
   - нужный лог — только конкретного прогона: `gh run view <id> --log | grep …`.
2. **Данные:** листы Google — точечным диапазоном через коннектор; архивы — из репозитория. Сеть песочницы закрыта для
   t.me, ESPN, tennis-data: проверять через облачный прогон.
3. **Изменение:**
   - офлайн-тест (`PYTHONDONTWRITEBYTECODE=1`, `ast.parse`, импорт модулей) → коммит ЯВНЫМИ путями (`git add <файлы>`);
   - `__pycache__` не добавлять и отслеживаемые не удалять (`git checkout -- __pycache__`);
   - `football/test_offline.py` меняет файлы данных — после него `git checkout -- football/data`.
4. **Push:** `git pull --rebase origin main && git push origin HEAD:main` (локальная ветка может называться иначе).
   Запуск облака: `gh api -X POST repos/vassoffat-cell/tennisbot/actions/workflows/<yml>/dispatches -f ref=main [-f 'inputs[...]=…']`.
   Workflow YAML проверять `yaml.safe_load`.
5. **Коммит** заканчивается строками атрибуции из system-reminder сессии (Co-Authored-By и Claude-Session).
6. **Новое решение пользователя** — строкой в CONTROL.md (дата, суть, где, проверка). Ошибка — в журнал CONTROL §3.
   Исследование — в IMPROVE.md. Затем синхронизировать документ в проект.
7. **Запреты:**
   - секреты не читать и не показывать; Apps Script не менять (только готовить код);
