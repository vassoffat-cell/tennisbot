# Standing in motion — вход для любого чата, задачи и Claude Code

Этот файл Claude читает автоматически при открытии репозитория. Порядок старта (решение пользователя 18.11.2026, CONTROL Ц9):

1. `engine/START.md` — карта системы, состояние, задачи (подгружается ниже автоматически).
2. `engine/CONTROL.md` — реестр решений пользователя: прочитать ПЕРЕД любым изменением; нарушать нельзя.

Пользователь не программист, работает с iPhone: ответы коротко, по-русски, с точными цифрами.
