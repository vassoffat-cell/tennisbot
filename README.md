# TennisBot — автономный прогноз WTA/ATP

Система работает в двух режимах, которые пишут в одну Google Таблицу:

| Режим | Где работает | Что делает |
|---|---|---|
| **Авто** (основной) | облако GitHub Actions, бесплатно, компьютер не нужен | 4 раза в сутки берёт расписание WTA/ATP (ESPN), прогнозирует все матчи основного тура на 36 часов вперёд, присылает прогноз в Telegram, рассчитывает доигранные матчи. По понедельникам и средам скачивает tennis-data, переобучает модель и подтягивает закрывающие коэффициенты для проверки |
| **Ручной** (по желанию) | бот на вашем компьютере | скриншоты 1xBet → прогноз по всем линиям букмекера и сигналы EV ≥ 5% |

Модель не видит котировок: прогноз строится только по данным игроков (Elo, подача/приём, возраст, усталость, покрытие, отдых, защита очков, личные встречи, рейтинг) и точной марковской цепи с momentum.

## 2. Компьютер (ручной режим) — уже настроен

- Python 3.13: `%LOCALAPPDATA%\Python\pythoncore-3.13-64\python.exe`
- Tesseract с русским языком
- `.env` с `BOT_TOKEN`, `ALLOWED_USERS`, `TESSERACT_CMD`
- `run_bot.bat` запускает бота.

После раздела 3 добавьте в `.env` строку `SHEET_ID=…` и положите `service_account.json` в папку бота: тогда бот тоже будет писать в Google Таблицу.

## 3. Google Таблица (обязательно для авто-режима)

1. Откройте https://console.cloud.google.com/ и войдите своим Google-аккаунтом. Соглашение примите; платёжная карта не нужна.
2. Вверху нажмите «Select a project» → «New project», дайте имя `tennis` → «Create». Убедитесь, что проект выбран.
3. Слева «APIs & Services» → «Library». Найдите **Google Sheets API** → «Enable». Затем найдите **Google Drive API** → «Enable».
4. «APIs & Services» → «Credentials» → «Create credentials» → **Service account**. Имя `tennis-bot` → «Create and continue» → «Done».
5. Нажмите на созданный аккаунт → вкладка **Keys** → «Add key» → «Create new key» → **JSON** → «Create». Скачается файл. Переименуйте его в `service_account.json` и положите в `C:\tennisbot`.
6. Откройте `service_account.json` Блокнотом и найдите строку `"client_email": "tennis-bot@….iam.gserviceaccount.com"`. Скопируйте этот адрес.
7. Создайте пустую Google Таблицу (sheets.google.com → «Пустая»), назовите её `Tennis`.
8. В таблице: «Настройки доступа» → вставьте адрес из шага 6 → роль **Редактор** → «Отправить».
9. Из адреса таблицы `https://docs.google.com/spreadsheets/d/ЭТО_ID/edit` скопируйте ID — длинную строку между `/d/` и `/edit`.
10. В `.env` впишите `SHEET_ID=ЭТО_ID`.
11. Проверка: дважды щёлкните `run_auto.bat`. В таблице появятся листы `auto_forecasts`, `paper_bets` и `summary` (лист `forecasts` — после первого ручного прогноза), а в Telegram придёт прогноз на ближайшие матчи (если они есть в расписании).

**Не публикуйте `service_account.json` и `.env`**: в них ключи доступа.

## 4. Облако GitHub Actions — работа без компьютера

### 4.1. Репозиторий
1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Справа вверху «+» → «New repository». Имя `tennisbot`, отметьте **Private** → «Create repository».
3. На странице репозитория нажмите ссылку **uploading an existing file**.
4. Откройте `C:\tennisbot` и выделите всё, **кроме** `.env`, `service_account.json` и папки `logs`. Перетащите в окно браузера, дождитесь загрузки → «Commit changes».
5. Проверьте, что папка `.github` загрузилась (на главной странице должен быть каталог `.github`). Если её нет:
   - «Add file» → «Create new file»;
   - имя файла: `.github/workflows/daily.yml`; содержимое — из файла `C:\tennisbot\.github\workflows\daily.yml` (откройте Блокнотом, скопируйте всё) → «Commit changes»;
   - то же самое для `.github/workflows/weekly.yml`.

### 4.2. Секреты (ключи хранятся в GitHub зашифрованно)
«Settings» (вкладка репозитория) → слева «Secrets and variables» → «Actions» → «New repository secret». Создайте четыре секрета:

| Name | Secret |
|---|---|
| `BOT_TOKEN` | токен бота (как в `.env`) |
| `ALLOWED_USERS` | ваш Telegram ID (как в `.env`) |
| `SHEET_ID` | ID таблицы (как в `.env`) |
| `GOOGLE_CREDENTIALS_JSON` | всё содержимое `service_account.json`: откройте Блокнотом, Ctrl+A, Ctrl+C, вставьте |

### 4.3. Первый запуск
1. Вкладка **Actions**. Если GitHub спросит, нажмите «I understand my workflows, go ahead and enable them».
2. Слева «weekly» → справа «Run workflow» → «Run workflow».
3. Через 3–6 минут должна появиться зелёная галочка, а в Telegram — отчёт об обновлении и прогноз на ближайшие матчи.
4. Если появился красный крестик, нажмите на запуск → на красный шаг, сделайте скриншот текста и пришлите разработчику.

Дальше всё идёт само:

| Когда (Ташкент) | Что |
|---|---|
| 00:17, 06:17, 12:17, 18:17 | прогноз новых матчей, расчёт доигранных, сводка |
| пн и ср 07:23 | скачивание tennis-data, переобучение модели, коэффициенты для проверки, отчёт |

Бесплатного лимита GitHub (2000 минут в месяц для приватного репозитория) хватает с большим запасом: система тратит около 300 минут в месяц.

## 5. Что приходит в Telegram

```
06.11 09:00 WTA Prudential Hong Kong Tennis Open · Quarterfinal · Hard
  Sorana Cirstea 76% (K≥1.38) — Mary Stoiana 24% (K≥4.40)
  тотал 20.5: Б 50% / М 50% · фора Ф1(-4.5) ≈50% · 1-й сет П1 68% · мало данных (12 матч.)
```
- **76%** — вероятность победы по модели.
- **K≥1.38** — минимальный коэффициент 1xBet, при котором ставка даёт EV ≥ 5% по модели. Если в 1xBet коэффициент выше, это сигнал модели.
- **тотал 20.5** — линия, на которой «больше» и «меньше» ≈ 50/50 по модели. Если у 1xBet основная линия другая, значит, модель и букмекер расходятся в ожидаемой длине матча.
- **мало данных** — у одного из игроков меньше 15 матчей в базе, прогноз менее надёжен.

Команды бота на компьютере: `/today` — авто-прогнозы на ближайшие матчи, `/stats` — качество модели и итоги, `/update` — обновить данные на компьютере, `/reset`.

## 6. Листы таблицы

| Лист | Что в нём |
|---|---|
| `auto_forecasts` | каждый матч основного тура: время, игроки, P, K_fair, K_min, тотал, фора, 1-й сет, счёт по сетам → результат, лог-лосс → закрывающие коэффициенты Bet365 / средний / максимум / Betfair → бумажная ставка на победителя и её результат |
| `summary` | лог-лосс и точность модели, сравнение с рынком, ROI бумажных ставок с 95% интервалом, калибровка по корзинам |
| `forecasts`, `paper_bets` | ручные прогнозы по скриншотам 1xBet и их расчёт |

**Как читать `summary`:**
- **лог-лосс модели против рынка** — главный показатель; меньше — лучше. Пока у модели он выше, чем у рынка без маржи, её прогноз хуже букмекерского.
- **ROI ± 95%** — если интервал целиком выше нуля, у модели есть преимущество; если целиком ниже — модель проигрывает.
- **калибровка** — в корзине «70–80%» фактическая доля побед должна быть около 75%.

Выводы — не раньше чем через 200–300 доигранных матчей. В неделю основной тур даёт 100–200 матчей, то есть 2–3 недели.

## 7. Самообучение

- **Каждый день** результаты из ESPN добавляются в форму игроков (Elo, усталость, отдых, личные встречи), поэтому прогноз учитывает вчерашние матчи.
- **Пн и ср** модель переобучается по всей истории, включая прошедшую неделю: обновляются веса всех признаков и статистика игроков. Отчёт показывает качество модели на проверочной выборке 2023+.
- Новые данные в `auto_forecasts` (прогноз до матча → результат → коэффициенты рынка) — основа для следующего шага: настройки модели на её собственных живых ошибках.

## 8. Неполадки

| Симптом | Решение |
|---|---|
| Красный крестик в Actions, шаг «Ключ Google» или ошибка `SpreadsheetNotFound` / `403` | таблица не открыта сервисному аккаунту как «Редактор», неверный `SHEET_ID`, не включены Sheets API и Drive API |
| В Telegram ничего не приходит | неверный `BOT_TOKEN` или `ALLOWED_USERS` в секретах; вы ни разу не нажали `/start` у бота |
| `ESPN …: нет данных` | источник временно недоступен — следующий запуск через 6 часов повторит |
| «игрок не опознан» | игрок слишком новый (нет в базе Sackmann до 05.2026) — матч пропускается |
| Бот на ПК: `TesseractNotFoundError` | путь `TESSERACT_CMD` в `.env` |

## 9. Ограничения

- Авто-режим прогнозирует только турниры основного тура (города из tennis-data) и Шлемы; квалификации, WTA 125, челленджеры и ITF пропускаются.
- Коэффициентов 1xBet в авто-режиме нет (бесплатного источника не существует). Проверка на рынке идёт по закрывающим коэффициентам Bet365, среднему и максимуму из tennis-data — только для победителя матча. Тоталы и форы проверяются по лог-лоссу без денег.
- Статистика подачи и приёма — архив Sackmann по 25.05.2026; для новых матчей она не пополняется, остальные признаки обновляются.
