# TennisBot — автономный прогноз WTA/ATP

Всё работает в облаке, бесплатно, без компьютера:

| Компонент | Где | Что делает |
|---|---|---|
| Облако | GitHub Actions, каждые 2 часа (00:00, 02:00 … 22:00 по Ташкенту) | расписание и результаты ESPN, рейтинги ATP/WTA, прогноз, расчёт, самообучение, сообщения в Telegram |
| Бот с кнопками | Google Apps Script (привязан к Google Таблице) | меню: прогноз, аналитика, отчёт; приём файлов tennis-data |
| Хранилище | Google Таблица + приватный репозиторий GitHub | все прогнозы, линии, результаты, модель |

## 1. Прогноз на 24 часа

- Каждые 2 часа приходит свежий список матчей на ближайшие 24 часа, предыдущий удаляется. Последнее сообщение в чате — всегда актуальные данные для ставок.
- Звук уведомления — только когда в списке появились новые матчи; плановые обновления приходят без звука.
- Начавшиеся и завершённые матчи из списка исчезают и уходят в журнал для самообучения.
- Если матчей нет (межсезонье), бот молчит, но продолжает проверять календарь каждые 2 часа.
- Турниры: Большой шлем, 1000, 500, 250 и итоговые, только основная сетка.

Карточка матча:
```
🎾 ATP 1000 · Rolex Paris Masters
🕒 07.11 00:30 · 1/4 · хард
Casper Ruud — Nuno Borges

П1 Ruud: если кф 1.38 – 1.57
Фора по геймам 1 (-2.5): если кф 1.40 – 1.60
Инд. тотал 1 · М 14.5: если кф 1.39 – 1.59
Инд. тотал 2 · Б 9.5: если кф 1.41 – 1.62
Тотал · М 24.5: если кф 1.40 – 1.60
🎯 Уверенность ●●●○○ средняя · модель: Ruud 72%
```

## 2. Как считается диапазон кф

- Для каждой линии модель даёт вероятность P (точная марковская цепь гейм → тай-брейк → сет → матч с momentum).
- **Диапазон системы:** от (1 + 5%) / P до (1 + 20%) / P.
  - Ниже нижней границы ставка невыгодна (EV < 5%).
  - Выше верхней границы расхождение с рынком слишком велико; чаще всего это значит, что ошибается модель, потому что рынок знает о травме, мотивации или другой информации. Бэктест 2023–2026 это подтверждает: при EV 5–20% ROI −9,1 ± 2,9%, при EV > 50% ROI −19,8 ± 9,0%.
- **Зона ставок 1,35–1,65:** линии форы и тоталов подбираются так, чтобы диапазон попадал в эту зону (P ≈ 0,75). Показывается часть системного диапазона внутри зоны. Линии вне зоны (например, П2 при кф 4,5) не показываются, но записываются в журнал и участвуют в самообучении.
- Зона и границы EV меняются в `config.py`: `ODDS_ZONE`, `EV_THRESHOLD`, `EV_MAX`.

## 3. Самообучение

| Механизм | Как часто | Что меняется |
|---|---|---|
| Форма игроков | каждые 2 ч | результаты ESPN → Elo, усталость, отдых, личные встречи |
| Рейтинг ATP/WTA | каждые 2 ч | из ESPN, без ручных файлов |
| Расчёт всех линий | каждые 2 ч | W / L / возврат по каждой линии; при отказе или отмене матча — возврат |
| Самокалибровка по рынкам | каждые 2 ч | для каждого рынка (победа, фора, инд. тоталы, тотал) отдельный коэффициент k: P' = σ(k·logit P), по фактическим результатам; включается после 30 рассчитанных |
| Переобучение | через день в 00:00 и после новых файлов | веса всех признаков |
| Итоги самообучения | каждый день в 00:00 | сообщение в Telegram: за сутки, всего, по рынкам, k |
| Отчёт для Claude | после каждых 10 доигранных матчей | сообщение в Telegram для пересылки |

## 4. Кнопки бота

| Кнопка | Что показывает |
|---|---|
| 📋 Прогноз 24 ч | актуальный список (удалится при следующем обновлении) |
| 📊 Аналитика | за всё время: угадано, лог-лосс, ROI по каждому рынку (по нижнему кф диапазона), проверка по Bet365 |
| 📅 За месяц | то же за выбранный месяц |
| 🗓 За период | то же за период `01.11.2026-15.11.2026` |
| 🏆 По турниру | то же по выбранному турниру |
| 🧾 Отчёт для Claude | подробный отчёт с калибровкой и сводкой облака — переслать Claude |
| 🧹 Очистить чат | удаляет сообщения последних 48 часов (раньше Telegram удалять не даёт) |

## 5. Раз в неделю — файлы tennis-data (по желанию)

Скачайте в браузере http://www.tennis-data.co.uk/2026w/2026.xlsx и http://www.tennis-data.co.uk/2026/2026.xlsx и отправьте боту. Имя файла не важно: тур определяется по содержимому.

Бот положит файлы в папку Google Диска `tennisbot_inbox`. Облако заберёт их в течение 2 часов, переобучит модель, подтянет закрывающие кф Bet365 / средний / максимум для проверки и пришлёт подтверждение.

Без файлов система работает дальше: форма и рейтинги обновляются по ESPN. Не будет только проверки против закрывающих кф рынка. Сайт tennis-data закрыт для серверов, и система эту блокировку не обходит.

## 6. Листы таблицы

| Лист | Содержимое |
|---|---|
| `auto_forecasts` | матч: уровень, время, игроки, P после самокалибровки и P модели, тотал, фора, 1-й сет, счёт по сетам, уверенность → результат, лог-лосс → закрывающие кф и проверочная ставка |
| `auto_lines` | 7 линий каждого матча: рынок, линия, P, диапазон системы, показанный диапазон → результат, прибыль по нижнему кф |
| `summary` | сводка качества |
| `tg_messages` | служебный: списки, запрошенные кнопкой, для удаления |

## 7. Ограничения

- Коэффициентов 1xBet в системе нет (бесплатного источника не существует). Решение о ставке принимается по правилу «кф 1xBet внутри диапазона».
- В бэктесте модель без котировок уступала закрывающей линии рынка. Обыгрывает ли она рынок вживую, покажет аналитика на 200–300 матчах.
- Статистика подачи и приёма — архив Sackmann по 25.05.2026, она не пополняется. Остальные признаки обновляются.
