# TennisBot — автономный прогноз WTA/ATP в облаке

Работает полностью в облаке GitHub Actions (бесплатно): компьютер не нужен. Данные — в приватном репозитории GitHub и в Google Таблице, сообщения — в Telegram.

## 1. Что делает система

| Когда (Ташкент) | Что |
|---|---|
| 00:00, 06:00, 12:00, 18:00 | забирает входящие из Telegram (файлы tennis-data, /stats) → берёт расписание ESPN → прогнозирует новые матчи на 36 часов вперёд → присылает карточки в Telegram и пишет в таблицу → рассчитывает доигранные → сохраняет результаты |
| через день в 00:00 (с 06.11.2026) и сразу после получения файлов tennis-data | переобучение модели + отчёт |

Турниры: **Большой шлем, 1000, 500, 250 и итоговые** (WTA и ATP), только основная сетка. Квалификации, WTA 125, челленджеры и ITF пропускаются.

GitHub запускает задания по расписанию с задержкой от нескольких минут (в часы пик — до 15–30 минут).

- **Сообщения** приходят только тогда, когда в календаре появились новые матчи с известными соперниками.
- **Дублей нет**: каждый матч (ID ESPN) прогнозируется и отправляется один раз.

## 2. Как модель учится

| Механизм | Как часто | Что меняется |
|---|---|---|
| Форма игроков | каждый запуск | результаты ESPN докатываются в Elo, усталость, отдых, личные встречи (`data/espn`) |
| Переобучение | через день | веса всех признаков пересчитываются по всей истории (tennis-data + новые недели) |
| Самокалибровка | каждый запуск | модель сравнивает свои прошлые прогнозы с результатами: P' = σ(k·logit P). k > 1 — была слишком осторожной, k < 1 — слишком самоуверенной. Поправка растёт вместе с числом доигранных матчей (априорная сила 300 матчей) |
| Уверенность | в каждой карточке | 1–5: объём данных по игрокам + фактическая точность модели в той же корзине вероятностей + сравнение лог-лосса с рынком |

Самообучение исправляет систематические ошибки модели (перекос вероятностей), но не даёт ей информации, которой у неё нет: травмы, мотивация, новости. Узнать, обыгрывает ли модель рынок, можно только по листу `summary`.

## 3. Карточка в Telegram

```
🎾 ATP 1000 · Rolex Paris Masters
🕒 06.11 15:00 · 3-й круг · хард
Jannik Sinner — Alex De Minaur

📊 Модель: Jannik Sinner 86% · Alex De Minaur 14%
✅ Ставка: П1 Jannik Sinner при кф ≥ 1.23
↔️ П2 Alex De Minaur — только при кф ≥ 7.27
📏 Тотал 20.5: Б 51% · кф ≥ 2.05
🎯 Уверенность: ●●●●○ высокая
```
**кф ≥** — минимальный коэффициент 1xBet, при котором ставка выгодна по модели (EV ≥ 5%): K_min = 1,05 / P. Если в 1xBet коэффициент ниже, это пропуск. Полная роспись матча — справедливые кф, фора, 1-й сет, счёт по сетам — в листе `auto_forecasts`.

## 4. Раз в неделю: файлы tennis-data (1 минута)

1. В браузере скачайте http://www.tennis-data.co.uk/2026w/2026.xlsx (WTA) и http://www.tennis-data.co.uk/2026/2026.xlsx (ATP).
2. Отправьте оба файла боту в Telegram как документы.
3. Ближайший запуск (максимум через 6 часов) заберёт их, ответит «Файл принят», переобучит модель и подтянет закрывающие коэффициенты Bet365 / средний / максимум для проверки бумажного ROI.

Без файлов система работает дальше (форма обновляется по ESPN), но не обновляются рейтинги игроков и не считается ROI против рынка. Сам сайт tennis-data облачным серверам отказывает (403), и система эту блокировку не обходит.

Команда `/stats` в Telegram выдаёт сводку качества модели со следующим запуском.

## 5. Листы Google Таблицы

| Лист | Что в нём |
|---|---|
| `auto_forecasts` | каждый матч: время, уровень турнира, игроки, P (после самокалибровки) и P исходной модели, кф_fair, кф_min, тотал, фора, 1-й сет, счёт по сетам, уверенность → результат, лог-лосс → закрывающие кф и бумажная ставка на победителя |
| `summary` | лог-лосс и точность модели, сравнение с рынком, ROI ± 95%, калибровка по корзинам, коэффициент самокалибровки |

Выводы делайте после 200–300 доигранных матчей, это 2–3 недели.

## 6. Настройка (сделано)

- **Google Таблица** и сервисный аккаунт; ключ — в секрете GitHub `GOOGLE_CREDENTIALS_JSON`.
- **Секреты GitHub:** `BOT_TOKEN`, `ALLOWED_USERS`, `SHEET_ID`, `GOOGLE_CREDENTIALS_JSON`.
- **Расписание:** один файл `.github/workflows/daily.yml` (задание `tennis`).
- **Ручной запуск:** Actions → tennis → Run workflow.

## 7. Компьютер

Компьютер не нужен. Папку `C:\tennisbot` можно удалить — всё есть в репозитории.

**Не запускайте `bot.py`**: Telegram отдаёт входящие только одному получателю, и облако перестанет получать файлы.

Модуль скриншотов 1xBet (`bot.py`, `ocr.py`, `pipeline.py`, `analyze.py`) отключён, но код сохранён в репозитории.

## 8. Неполадки

| Симптом | Решение |
|---|---|
| Красный крестик, ошибка `SpreadsheetNotFound` / `403` | таблица не открыта сервисному аккаунту как «Редактор», неверный `SHEET_ID` |
| Нет сообщений | в ближайшие 36 часов нет новых матчей основного тура; или неверные `BOT_TOKEN`/`ALLOWED_USERS` |
| «входящие не прочитаны: на компьютере запущен бот» | закройте `bot.py` на компьютере |
| «игрок не опознан» | игрок новый (нет в базе) — матч пропускается |

## 9. Ограничения

- Коэффициентов 1xBet в системе нет (бесплатного источника не существует). Решение о ставке — по правилу «кф 1xBet ≥ кф_min».
- Проверка на рынке — по закрывающим коэффициентам tennis-data, только для победителя матча.
- Статистика подачи и приёма — архив Sackmann по 25.05.2026, она не пополняется. Остальные признаки обновляются.
